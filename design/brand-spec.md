# GROW.md website design

Selected: 01-workstation.png, generated with built-in imagegen before implementation. 02-phosphor.png was compared as an alternative. Exact prompts are in prompts.json.

The workstation direction matches the real opening art and leaves a clean left column for the title and download. Keep the second direction's large battle crop and cyan ASCII detail. Generated mockups guide composition only; shipped game screenshots and artwork remain the actual product assets.

Audience: game jam visitors, curious players. First impression: a tiny agent in a big machine. Primary action: download the native desktop game. Secondary action: watch a 30-second development gameplay reel.

Palette: near-black #070b10, warm white #e4ddca, lime #bfd878, cyan #71dfe3, muted #93968a. Blue comes from the original pixel art. Monospace labels; large bold Chinese headline. Thin terminal rules, square corners, no generic card grid. Desktop hero is a wide workstation; mobile stacks the art and text. Subtle cursor and idle animation respect reduced-motion preferences.

Verified product facts: Kessoku Works; real-time command battles; Skill authoring; persistent GROW.md experiences; MCP tools; Chinese/English UI and voices; native Windows and macOS. No browser playable build. The website repository contains promotional assets, not the private game source. Download is the existing 0.2.1-bilingual.2 package.
